# ⚡ Manutenção Preditiva de Ativos

> Manutenção preditiva de ativos do setor elétrico (transformadores, turbinas, linhas) com IoT e ML, evitando falhas, apagões e custos de manutenção corretiva.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/energia-manutencao-preditiva/

[![Setor](https://img.shields.io/badge/Setor-Energia-blue)]() [![IA](https://img.shields.io/badge/IA-IoT-green)]() [![Demo](https://img.shields.io/badge/Demo-Interativa-orange)]() [![Dados](https://img.shields.io/badge/Dados-CSV%2FExcel-success)]()

## 📊 Resultados-chave (KPIs)
**-54%** Falhas · **+22%** Disponib. · **-31%** Custo · **monitor.** Ativos

## 🧠 Tecnologias de IA
IoT · ML · Predictive Maintenance

## ✨ O que faz
- Predição de falha por ativo
- Telemetria IoT
- Agendamento ótimo
- Prevenção de apagão
- Redução de custo O&M

## 🗄️ Fonte de dados real
[Telemetria + ANEEL](https://www.gov.br/aneel) — bases de entrada e resultados disponíveis para download em CSV/Excel no app.
